Write Playwright E2E tests from the approved test plan.

$ARGUMENTS can be: a work item ID, a path to `e2e-tests.md`, a spec folder path, or empty (uses `.claude/current-workitem`, or `e2e-tests.md` in project root).

## Step 1 — Resolve e2e-tests.md

- Number → glob `specs/**/<number>-*/e2e-tests.md`.
- Ends with `e2e-tests.md` → use directly.
- Folder → append `/e2e-tests.md`.
- Empty → try `.claude/current-workitem`, then project root `e2e-tests.md`.
- Not found → "No e2e-tests.md found. Run /write-e2e-tests first." and stop.

## Step 2 — Read e2e-tests.md and resolve open questions

Read fully. If "Open Questions" is non-empty: use `AskUserQuestion` (up to 4 per round, default options). Rewrite section.

## Step 3 — Bootstrap Playwright (if needed per "Setup needed")

a. **Install** (if `@playwright/test` absent from package.json):
   ```bash
   npm install -D @playwright/test && npx playwright install --with-deps chromium
   ```

b. **Create `playwright.config.ts`** if missing — use values from "Playwright Setup" table:
   - `testDir`, `baseURL`, `webServer.command`, `webServer.url` from the plan
   - `fullyParallel: true`, `forbidOnly: !!process.env.CI`, `retries: process.env.CI ? 2 : 0`
   - Projects: chromium (+ firefox/webkit if listed)

c. **Create `e2e/`** directory if missing.

d. **Add `.gitignore` entries**: `/test-results/`, `/playwright-report/`, `/blob-report/`, `/playwright/.cache/`

## Step 4 — Full or delta mode

Check for `e2e-tests.snapshot.md`:

**No snapshot → Full mode.** **Snapshot exists → Delta mode** (compare, print delta, ask about removals).

## Step 5 — Create Page Object Models

For each POM in "Page Object Models" section (skip if absent or already exists):
- Create class at specified path using `page.getByRole`, `getByLabel`, `getByText`.
- Export as named export.

## Step 6 — Create global fixtures/setup

Implement `globalSetup.ts`, `fixtures.ts` etc. from "Global Fixtures / Setup" section. Reference in `playwright.config.ts`. Skip if absent.

## Step 7 — Implement spec files

For each spec file (all in full mode; delta-only in delta mode):
1. Import POMs if applicable.
2. Each test table row → one `test()` block.
3. Preconditions → `test.beforeEach` (if shared) or inline.
4. Steps → Playwright actions (`goto`, `fill`, `click`, `press`).
5. Expected → Playwright assertions (`toBeVisible`, `toHaveText`, `toHaveURL`).
6. Group with `test.describe`.
7. Confirm: `✓ e2e/<file>.spec.ts — N tests`

## Step 8 — Verify and finish

1. Check "Acceptance Criteria Coverage" — confirm all mapped. Write minimal test if gap found.
2. Save `e2e-tests.md` to `e2e-tests.snapshot.md` (only on full success).
3. Print summary:
   ```
   Playwright E2E tests implemented for <Type> #<ID>: <Title>
   Files changed:
   - created  playwright.config.ts
   - created  e2e/pages/todo.page.ts  (POM)
   - created  e2e/todos.spec.ts       (3 tests)
   Run: npx playwright test
   Report: npx playwright show-report
   Snapshot saved.
   ```

## Playwright best practices

- **Selectors**: `getByRole`, `getByLabel`, `getByText`, `getByPlaceholder` — never CSS/XPath.
- **Waiting**: never `waitForTimeout`. Use auto-waiting, `waitForURL`, `waitForResponse`.
- **Isolation**: each test starts clean. No shared mutable state.
- **Assertions**: `expect` from `@playwright/test` only.
- **Flakiness**: `await expect(locator).toBeVisible()` before interacting with animated elements.

## Rules

- Do not modify source application files — only test and config files.
- Do not add tests beyond `e2e-tests.md`. Mention gaps in summary.
- If dev server fails, print error and tell user to fix — do not retry.
